# Cloud AI FDE Agent Software Factory (`fde-agent-factory`) — Plugin & OKF Index

**`fde-agent-factory`** packages the reusable meta-configuration, skills, slash-command workflows, `PreToolUse` security/documentation hooks, and Google Operational Knowledge Framework (OKF) + Mermaid architecture templates needed to stand up or upgrade an **Agentic Software Factory** in any repository.

---

## Quickstart & Consumption Modes

### Mode 1: Clone & Link into an Existing Repository (Live Bidirectional Plugin Development)
Clone `fde-agent-factory` into your repository (either directly as `.agents` or in a subdirectory) and run `./install.sh --link`. All skills, workflows, hook scripts, Gemini CLI slash commands (`.gemini/commands/`), `AGENTS.md` rules, `.gitmessage.txt`, and OKF templates are wired via relative symlinks directly to the `fde-agent-factory` Git repository—so **any change you make locally in your workspace automatically updates the tracked files inside the `fde-agent-factory` plugin repo**:

```bash
# Option 1A: Clone directly as .agents/ in your existing repository
rm -rf .agents
git clone https://github.com/<ORG>/fde-agent-factory.git .agents
./.agents/install.sh --link

# Option 1B: Or link from a ./fde-agent-factory clone inside your workspace
./fde-agent-factory/install.sh --link .

# Whenever you edit skills, workflows, hooks, or slash commands in the host repo,
# commit and push them directly back to the plugin repository:
git -C .agents status
git -C .agents add -A
git -C .agents commit -F - <<'EOF'
feat(skills): update skill or workflow

Why:
- Keep shared Software Factory plugin synchronized with workspace improvements.

What:
- Updated skill/workflow definitions.

Verification:
- ./install.sh --verify passed all unit tests.
EOF
git -C .agents push
```

### Mode 2: Stand Up a Brand-New Software Factory Repository (`--copy`)
To bootstrap a new repository with standalone copies of all skills, workflows, slash commands, OpenSpec SDD config, and Mermaid + OKF starter docs:

```bash
./fde-agent-factory/install.sh --copy /path/to/new-repo
```

### Mode 3: Native Jetski / Antigravity Plugin (`plugin.json`)
Because the root of `fde-agent-factory` includes [`plugin.json`](plugin.json), [`hooks.json`](hooks.json), [`rules/AGENTS.md`](rules/AGENTS.md), and [`skills/`](skills/), it can also be mounted directly under `~/.gemini/config/plugins/fde-agent-factory/` or `_agents/plugins/fde-agent-factory/`.
